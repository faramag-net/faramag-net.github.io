# Fotografías públicas de Eventos

Coloca aquí las fotografías públicas que utiliza `pages/eventos/eventos.js`.

Cada colección puede tener su propia subcarpeta, por ejemplo:

- `estacion-nieves/`
- `chamoyadas/`
- `paletas-cobertura/`

Las rutas se declaran manualmente en el arreglo `eventos` de `pages/eventos/eventos.js`.
No colocar aquí fotografías privadas de IndexedDB (Mapa, Visitas, Mercado o Compras).

Las rutas de imagen se escriben relativas a `pages/eventos/index.html`, por ejemplo:
`../../imagenes/eventos/chamoyadas/portada.webp`
